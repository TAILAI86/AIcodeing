一个用 AI 从零写出来的小游戏合集。目前收录：

## 🏭 金币工厂（挂机小游戏）

一个单文件网页放置游戏 —— **双击 HTML 就能玩**，无需安装、无需联网、无需任何外部资源。

```bash
# 下载
git clone https://github.com/TAILAI86/game.git
# 打开
start 挂机小游戏\金币工厂.html
```

### 玩法

点击金币赚钱 → 雇员工自动产出 → 攒够身家重生换永久加成。

| 系统 | 说明 |
|---|---|
| 🛒 **商店** | 9 种升级：点击系 / 被动收益系 / 暴击系，价格指数增长 |
| ⚡ **暴击** | 基础 5% 概率 ×3 倍率，最高可叠到 100% |
| ♻️ **重生** | 累计 ≥ 100 万可重生，声望每点 **永久 +8% 全局收益** |
| 😴 **离线收益** | 关网页也在赚钱，回来结算（最多 8 小时） |
| 🧧 **幸运事件** | 每 45~120 秒随机触发，有增益也有横财 |
| 🏆 **成就** | 14 个成就，进度条实时显示，**每达成一个永久 +1.2% 全局收益** |
| 🤖 **自动采购** | 自动帮你买最便宜的升级 |
| 📅 **每日签到** | 7 天循环奖励，第 7 天送 **声望 +1**，断签重置 |
| 🌙 **暗色主题** | 设置里一键切换，深夜搬砖不刺眼 |
| 💰 **买满** | 商店每个升级可「买满」，一键采购到买不起为止 |
| 💾 **存档** | 自动保存 + 导出 JSON + 跨设备读取 |

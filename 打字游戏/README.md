# ⌨️ 打字风暴 · Typing Storm

> 一个用 AI 从零写出来的**单文件网页打字游戏** —— **双击 HTML 就能玩**，无需安装、无需联网、无需任何外部资源。

中文拼音打字 + 英文盲打 + 代码符号练习，5 种模式、技能树成长、段位段位、成就图鉴、每日挑战。

```bash
# 下载
git clone https://github.com/TAILAI86/game.git
# 打开（Windows）
start 打字游戏\打字游戏.html
# macOS / Linux
open 打字游戏/打字游戏.html
```

---

## 🎮 玩法

屏幕中央是当前要打的**词**，下面跟着对应的**拼音**。逐字敲击键盘上的字母即可 —— 中文打的是拼音（如「图书馆」→ `tu shu guan`），英文直接打单词。

| 系统 | 说明 |
|---|---|
| ⚡ **极速风暴** | 60 秒限时冲刺，比拼手速与爆发力 |
| 💀 **无限生存** | 生命值有限，威胁条持续上涨，每 25 秒词库自动升档 |
| 🎯 **精准挑战** | 一个错字整词重来，考验稳定性，零失误通关有额外加成 |
| 🏔️ **登峰造极** | 十级阶梯关卡，每关词更长更难，登顶通关 |
| 🔥 **连击狂潮** | 只追求最高连击，失误即清零，90 秒定胜负 |
| 📚 **自定义词库** | 粘贴任意文本 —— 中文自动转拼音、英文直接练，专攻课文 / 专有名词 / 考试重点 |
| 🩹 **错词复习** | 打错的词自动收进错词本，一键专项复习，针对性突破 |
| 🎯 **每日挑战** | 全服同题：模式 / 难度 / 词库由日期种子决定，比拼当日最高分 |
| ⏸️ **暂停** | 游戏中随时暂停（空格 / Esc），暂停时长不计入成绩 |

### 难度与语种

| 难度 | 中文词库 | 英文词库 | 初始生命 |
|---|---|---|---|
| 轻松 | 基础常用词 | 短词 | 4 |
| 普通 | 进阶词（需技能「博闻」） | 中等长度词 | 3 |
| 挑战 | 高阶成语（需技能「通识」） | 长词 | 2 |
| 地狱 | 文言词库 | 代码符号 | 1 |

语种支持 **中文拼音 / 英文 / 中英混合**（混合需技能「兼修」）。

| 分支 | 技能 | 效果 |

| | 👑 宗师之魂 | 连击破 30 后得分倍率额外 +0.1/级 |
| | ☄️ 陨星坠落 | 生存模式威胁增长 -9%/级 |
| 📚 **词海线** | 👁️ 慧眼 | 常驻显示下一个词的首字母提示 |
| | 📖 博闻 | 解锁进阶中文词库与英文长词 |
| | 🧠 通识 | 解锁高阶文言词库与代码符号 |
| | 🌏 兼修 | 解锁中英混合词流挑战 |

| | 🔰 护盾 | 每局免除失误次数 +1/级 |
| | 🎯 专注 | 失误后 1 秒内的按键不计错 |

### 🏆 成长与收集

- **等级 / 经验**：每局获得 XP，升级得 1 技能点
- **段位**：按最高速度划分 青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师 → 王者
- **星尘 ✦**：二级货币，来自签到与成就，用于解锁 6 款皮肤（极光 / 熔岩 / 翠竹 / 樱华 / 深海 / 鎏金）
- **成就图鉴**：32 项成就，覆盖速度、连击、累计字数、玩法与收集
- **📊 数据统计**：最近 12 局速度趋势折线图 + **键盘热力图**（用得多的键更亮，拖沓键标红框）+ **「拖沓键」分析**（找出你打起来最费劲的按键）

### 💾 存档

- 自动保存（localStorage），3 个独立存档槽，可切换 / 复制 / 重命名
- 支持导出 / 导入 JSON 文件，跨设备迁移
- 亮色 / 暗色双主题，设置与音效可独立开关

## ✨ 细节

- **实时反馈**：逐字高亮（正确绿 / 当前亮蓝 / 错误红）、连击数字跳动、失误时屏幕震动 + 边缘红闪
- **连击热度**：连击 ≥25 变暖色，≥60 燃起火焰粒子
- **音效**：WebAudio 实时合成（无音频文件），键音随连击升高，可切换清脆 / 柔和 / 机械三种音色
- **响应式**：桌面 / 平板 / 手机自适应，无横向溢出

# 金币工厂 · AI 小游戏

一个用 AI 从零写出来的小游戏合集。目前收录：

## 🏭 金币工厂（挂机小游戏）

一个单文件网页放置游戏 —— **双击 HTML 就能玩**，无需安装、无需联网、无需任何外部资源。

```bash
# 下载
git clone https://github.com/TAILAI86/game.git
# 打开
start 挂机小游戏\金币工厂.html
```

### 玩法

点击金币赚钱 → 雇员工自动产出 → 攒够身家重生换永久加成 → 用天赋点把收益推到下一个量级。

| 系统 | 说明 |
|---|---|
| 🛒 **商店** | 11 种升级：点击系 / 被动收益系 / 暴击系 / 离线增益系，价格指数增长 |
| 🌟 **天赋树** | 10 个永久天赋分三条线（财富 / 效率 / 稳健），用天赋点解锁，**永久保留** |
| 📋 **每日任务** | 每天自动刷新 3 个任务，完成领金币，**全清额外送 1 点天赋点** |
| ⚡ **暴击** | 基础 5% 概率 ×3 倍率，最高可叠到 100% |
| ♻️ **重生** | 累计 ≥ 100 万可重生，获 **声望 🌟**（每点 +8% 全局）与 **贤者水晶 🔮**（二级元货币，√(数量) 永久加成、永不封顶），并回馈天赋点 |
| 🔮 **贤者水晶** | 重生结晶出的二级元货币，提供 √(数量) **永久全局加成**，永不封顶 —— 中后期最强的长期目标 |
| 😴 **离线收益** | 关网页也在赚钱，回来结算；升级与天赋可提升离线倍率与结算上限（8h → 32h） |
| 🧧 **幸运事件** | 每 45~120 秒随机触发，有增益也有横财 |
| 🏆 **成就** | 22 个成就，进度条实时显示，**每达成一个永久 +1.2% 全局收益** |
| 🎖️ **里程碑** | 累计财富 12 档永久解锁（到「无量首富」约 1e30），**超档后每 10× 再 +2%，无限延伸**（重生不清空累计财富） |
| 📊 **数据分析** | 各升级 **回本时间排行** + 经营概况 + **实时收益曲线图**，一眼看出该买哪个 |
| 💰 **卖出退款** | 买错了能卖，返还该级投入的 **60%** |
| 🤖 **自动采购** | 自动帮你买最便宜的升级，**可逐个开关采购范围** |
| 📅 **每日签到** | 7 天循环奖励，第 7 天送 **声望 +1**，断签重置 |
| 🌙 **暗色主题** | 设置里一键切换，深夜搬砖不刺眼 |
| 💾 **存档** | 自动保存 + 导出 JSON + 跨设备读取 |
| 🎯 **智能目标** | 主界面动态推荐「下一步该干嘛」，相关页签亮红点提醒 |
| ♻️ **重生规划** | 重生面板测算「现在重生 vs 再攒」：下一声望点还要多久、重生后加成提升多少 |
| 🔮 **重生模拟器** | 重生面板内置模拟器，预览重生后全局加成与「最优采购顺序」，重生后先买哪个一目了然 |
| 📂 **多存档** | 3 个独立存档位，可切换 / 复制 / 清空 / 重命名，老存档自动迁移 |
| 📱 **移动端** | 手机自适应布局：标签页横向滑动、面板单列堆叠，随时随地搬砖 |

### 天赋树

天赋是 v1.0.0 的重头戏 —— 声望不再只是一个数字，而是能换来**实打实的永久成长**。

| 分支 | 天赋 | 效果 |
|---|---|---|
| 💰 财富 | 生财有道 | 全局收益 +4%/级（10 级） |
| 💰 财富 | 点石成金 | 点击收益 +12%/级（8 级） |
| 💰 财富 | 复利机器 | 离线收益 +20%/级（8 级） |
| ⚙️ 效率 | 批量议价 | 升级价格 -3%/级（8 级，最高 -24%） |
| ⚙️ 效率 | 幸运加成 | 暴击率 +3%/级（8 级） |
| ⚙️ 效率 | 通货膨胀 | 升级涨价幅度 -2%/级（8 级，最高 -16%） |
| 🍀 稳健 | 长线待机 | 离线结算上限 +2 小时/级（6 级） |
| 🍀 稳健 | 勤能补拙 | 每日任务奖励 +25%/级（6 级） |
| 🍀 稳健 | 细水长流 | 重生保留累计财富的 5%/级 作为启动资金（5 级） |
| 🍀 稳健 | 及时行乐 | 每次签到额外获得天赋点（5 级） |

**天赋点从哪来？** 重生回馈（每点声望约 0.5 点）、每日任务全清（+1 点）、签到（天赋「及时行乐」）。

## 🏭 金币工厂（挂机小游戏）

一个单文件网页放置游戏 —— **双击 HTML 就能玩**，无需安装、无需联网、无需任何外部资源。

```bash
# 下载
git clone https://github.com/TAILAI86/game.git
# 打开
start 挂机小游戏\金币工厂.html
```

### 玩法

点击金币赚钱 → 雇员工自动产出 → 攒够身家重生换永久加成 → 用天赋点把收益推到下一个量级 → 拿闲钱炒股坐享分红。

**核心循环**：*手动点击起步* → *买升级把点击变成被动收入* → *被动收入推高总财富、解锁里程碑与成就（永久加成）* → *财富到 100 万触发重生，把进度换成声望与贤者水晶* → *用天赋点横向拉开差距* → *用闲钱进股市博取差价与分红* → *面对更高目标继续循环*。每轮循环都会永久抬高下一轮的起点倍率。

### 天赋树

天赋是 v1.0.0 的重头戏 —— 声望不再只是一个数字，而是能换来**实打实的永久成长**。

| 分支 | 天赋 | 效果 |
|---|---|---|
| 💰 财富 | 生财有道 | 全局收益 +4%/级（10 级） |
| 💰 财富 | 点石成金 | 点击收益 +12%/级（8 级） |
| 💰 财富 | 复利机器 | 离线收益 +20%/级（8 级） |
| ⚙️ 效率 | 批量议价 | 升级价格 -3%/级（8 级，最高 -24%） |
| ⚙️ 效率 | 幸运加成 | 暴击率 +3%/级（8 级） |
| ⚙️ 效率 | 通货膨胀 | 升级涨价幅度 -2%/级（8 级，最高 -16%） |
| 🍀 稳健 | 长线待机 | 离线结算上限 +2 小时/级（6 级） |
| 🍀 稳健 | 勤能补拙 | 每日任务奖励 +25%/级（6 级） |
| 🍀 稳健 | 细水长流 | 重生保留累计财富的 5%/级 作为启动资金（5 级） |
| 🍀 稳健 | 及时行乐 | 每次签到额外获得天赋点（5 级） |

**天赋点从哪来？** 重生回馈（每点声望约 0.5 点）、每日任务全清（+1 点）、签到（天赋「及时行乐」）。

### 项目结构

《金币工厂》是**单文件**网页游戏，所有 HTML / CSS / JS 全部内联在一个文件里，没有构建步骤：

| 文件 | 说明 |
|---|---|
| `挂机小游戏/金币工厂.html` | 唯一源码与成品；双击即玩，无需任何依赖 |

代码（内联 `<script>`）按职责大致分为：

- **状态与存档**：`defaultState()` 定义全部进度字段；`load()/save()` 负责读写；`mergeState()` 处理多标签页增量合并（**持仓 / 天赋 / 收入来源 / 任务进度全部纳入合并，杜绝静默丢档**）
- **经济核心**：`incomePerSec()` 每秒收益、`globalMult()` 全局倍率、`cost(u)` 升级价格曲线、`marketDividend()` 股票分红
- **行情系统**：`ensureMarket()/marketPrice()/marketBuy()/marketSell()/renderMarket()` 负责行情主流程；v1.6.0 起拆分为 `marketPriceTick()`（价格波动）与 `marketPayDividend(dt)`（**按真实经过时间派息**，保证"界面显示的每秒分红"就是实际到账）；另有 `drawSpark()`（走势图）、`marketBuyBulk()` / `marketBuyMax()`（批量 / 买满）、`marketSmartPick()` / `marketSmartBuy()`（智能投资）、`marketSellAll()`（一键清仓）、`marketBuyPrice()` / `marketSellPrice()`（买卖价差口径）
- **成长系统**：重生 `doPrestige()`、天赋 `perkMult()`、里程碑 `checkMilestones()`、成就 `checkAch()`、挑战 `enterChallenge()/exitChallenge()`
- **界面渲染**：`refresh()` 与各 `renderXxx()` 按页签增量刷新；`switchTab()` 切换页签；行情大厅采用**引用缓存 + 局部更新**（`mktUI.cards`），避免整块重绘导致按钮闪烁与点击丢失
- **主循环**：底部 `setInterval` 每秒推进收益、事件、存档与各类检查

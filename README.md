## ⌨️ 打字风暴（打字游戏）

一个单文件网页打字游戏 —— **双击 HTML 就能玩**，支持**中文拼音打字**、英文盲打与代码符号练习。

```bash
# 打开
start 打字游戏\打字游戏.html
```

### 玩法

屏幕中央显示要打的**词**与对应**拼音**，逐字敲击键盘字母即可。

| 系统 | 说明 |
|---|---|
| ⚡ **5 种模式** | 极速风暴（60秒）/ 无限生存（血量+难度攀升）/ 精准挑战（错字重来）/ 登峰造极（10 关阶梯）/ 连击狂潮（只拼最高连击） |
| 🎯 **每日挑战** | 全服同题：模式 / 难度 / 词库由日期种子决定，比拼当日最高分 |
| 🌿 **技能树** | 12 项技能分三线（手速 / 词海 / 心流），升级得技能点自由分配 |
| 🏆 **成长体系** | 24 项成就 · 7 级段位（青铜→王者）· 6 款皮肤 · 等级与经验 |
| 📊 **数据统计** | 最近 12 局速度趋势折线图 + **「拖沓键」分析**（找出你打起来最费劲的按键） |
| 💾 **存档** | 3 个独立存档槽 · JSON 导出导入 · 亮暗双主题 · 音效与粒子可独立开关 |

**词库规模**：中文 500+ 词条（基础 / 成语 / 文言三档）、英文 400+ 单词、代码符号若干，全部人工校对拼音。

## 🏭 金币工厂（挂机小游戏）

一个单文件网页放置游戏 —— **双击 HTML 就能玩**。

```bash
# 打开
start 挂机小游戏\金币工厂.html
```

### 玩法

点击金币赚钱 → 雇员工自动产出 → 攒够身家重生换永久加成 → 用天赋点把收益推到下一个量级。

| 系统 | 说明 |
|---|---|
| 🛒 **商店** | 11 种升级：点击系 / 被动收益系 / 暴击系 / 离线增益系，价格指数增长 |
| 🌟 **天赋树** | 10 个永久天赋分三条线（财富 / 效率 / 稳健），**永久保留** |
| 📋 **每日任务** | 每天自动刷新 3 个任务，完成领金币，**全清额外送 1 点天赋点** |
| ⚡ **暴击** | 基础 5% 概率 ×3 倍率，最高可叠到 100% |
| ♻️ **重生** | 累计 ≥ 100 万可重生，获 **声望 🌟** 与 **贤者水晶 🔮**（二级元货币，永久全局加成、永不封顶） |
| 😴 **离线收益** | 关网页也在赚钱，回来结算；升级与天赋可提升离线倍率与结算上限（8h → 32h） |
| 🏆 **成就图鉴** | 22 个成就按 9 大分类分组陈列 |
| 🏅 **挑战模式** | 5 个独立冲刺挑战，达标永久提升全局倍率 |
| 📂 **多存档** | 3 个独立存档位，可切换 / 复制 / 清空 / 重命名 |
